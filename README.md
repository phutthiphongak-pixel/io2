# ครัวบ้านสวน — Restaurant POS

เว็บแอปตัวอย่างระบบจัดการร้านอาหารภาษาไทย สร้างด้วย Python + Flask + SQLite และหน้าเว็บ HTML/CSS รองรับงานสาธิตและต่อยอดโปรเจกต์วิชาเรียน

## เริ่มใช้งานบนเครื่อง

1. ติดตั้ง Python 3.10 ขึ้นไป
2. เปิดโฟลเดอร์โปรเจกต์ แล้วสร้าง virtual environment: `python -m venv .venv`
3. เปิด environment และติดตั้ง `pip install -r requirements.txt`
4. เริ่มระบบด้วย `python app.py`
5. เปิด `http://127.0.0.1:5000`

ฐานข้อมูล `instance/restaurant.db` และข้อมูลสาธิตจะถูกสร้างให้เมื่อเปิดระบบครั้งแรก

## บัญชีทดลอง

| บทบาท | ชื่อผู้ใช้ | รหัสผ่าน |
|---|---|---|
| ผู้ดูแลระบบ | `admin` | `admin123` |
| พนักงาน | `staff` | `staff123` |
| ลูกค้า | `customer` | `customer123` |

สมัครสมาชิกผ่านหน้าเว็บได้ แต่บัญชีที่สมัครใหม่จะเป็น customer เสมอ การกำหนด admin/staff ทำผ่านข้อมูลฝั่งผู้ดูแลเท่านั้น

## ฟังก์ชันในระบบ

- Login, สมัครสมาชิก, session และตรวจ Role ฝั่งเซิร์ฟเวอร์ (admin, staff, customer)
- Dashboard: ยอดขายวันนี้, ออเดอร์ค้าง, เมนูใกล้หมด และเมนูขายดี
- จัดการเมนู: เพิ่ม/แก้ไข/ลบ, หมวดหมู่, ราคา, ตัวเลือก, อัปโหลดรูป, สถานะหมด, ค้นหา/กรอง/เรียง/แบ่งหน้า และนำเข้า CSV
- จัดการโต๊ะ: เพิ่มโต๊ะและสถานะว่าง/มีลูกค้า/จอง
- ลบโต๊ะที่เพิ่มเองได้เมื่อยังไม่มีประวัติออเดอร์ (โต๊ะตัวอย่างเริ่มต้นลบไม่ได้ เพื่อรักษาข้อมูล)
- POS: สร้างออเดอร์ต่อโต๊ะ, ตัวเลือกเมนู, ยกเลิกรายการ, ย้ายโต๊ะ
- Kitchen Display: เรียงออเดอร์ตามเวลารับและเปลี่ยนสถานะกำลังทำ/เสร็จแล้ว
- หน้าเช็คบิลคำนวณค่าอาหาร ส่วนลด Service Charge, VAT, ยอดสุทธิ และเงินทอนแบบทันที
- Checkout/ใบเสร็จ: ส่วนลด, Service charge, VAT, วิธีชำระ, เงินทอน และพิมพ์
- รายงาน: ยอดขายรายวัน, รายได้รวม, ค่าเฉลี่ยต่อบิล และเมนูขายดี
- ประวัติการแก้ไขเมนู/โต๊ะ/ออเดอร์/ชำระเงิน
- จองโต๊ะ, ตัวอย่างไฟล์ TXT/CSV/JSON, ดาวน์โหลด CSV และ upload CSV
- หน้าลูกค้าแยกจาก Dashboard: สั่งอาหารตามแถบหมวดหมู่, จอง/ยกเลิกโต๊ะ และดูประวัติพร้อมสถานะคำสั่งซื้อ
- พนักงานดูรายการจองทั้งหมดและเลื่อนสถานะเป็น “พนักงานรับทราบ”, “ยืนยันแล้ว” หรือ “ยกเลิก” ได้
- เมนูกะเพราข้าวเลือกปกติ, พิเศษ (+10 บาท) หรือกับข้าว (+20 บาท) และบันทึกราคาหลังบวกเพิ่มในออเดอร์/ใบเสร็จ
- เมนูแสดงภาพประกอบตามหมวดโดยอัตโนมัติ แอดมินเพิ่มหรือเปลี่ยนรูปจริงได้ที่ **จัดการเมนู → แก้ไข** รองรับ PNG, JPG, WEBP และ GIF หรือเลือกกลับไปใช้ภาพหมวดได้
- ธีมสวนป่าใช้ IBM Plex Sans Thai พร้อมฟอนต์สำรองของระบบ มีภาพประกอบใบไม้/เถาวัลย์และหญ้าแบบจางเพื่อคงพื้นที่อ่านและกดใช้งานให้ชัดเจน
- หน้าครัวซ่อนออเดอร์จากคิวทันทีเมื่อกด “เสร็จแล้ว”
- เมนูตัวอย่างอาหารอีสานครบหมวด: ส้มตำ, ลาบ/ก้อย/น้ำตก/ซุป, ปิ้งย่าง/ทอด, ต้ม/แกง/อ่อม, ผัดกะเพรา, ข้าวและเครื่องดื่ม
- ออกจากบัญชีด้วยปุ่มด้านล่างแถบเมนู

หลังลูกค้าเข้าสู่ระบบ จะเปิดหน้าสั่งอาหารเป็นหน้าแรกโดยตรง และแสดงเฉพาะเมนูสั่งอาหาร, จองโต๊ะ, ประวัติคำสั่งซื้อ และออกจากบัญชี

เมนูใหม่ถูกเพิ่มให้อัตโนมัติทั้งฐานข้อมูลใหม่และฐานข้อมูลเดโมที่มีอยู่แล้ว ราคาที่ใส่เป็นราคาเริ่มต้นสำหรับสาธิต ผู้ดูแลแก้ไขราคาได้ที่ **จัดการเมนู → แก้ไข** ในแต่ละรายการ

แถบหมวดเมนูใช้ 7 หมวดคงที่: ของหวาน, อาหารอีสาน, ส้มตำ, น้ำ, อาหารตามสั่ง, ของทอด และของย่าง รายการเก่าจะถูกจัดเข้าหมวดใหม่โดยอัตโนมัติเมื่อเริ่มระบบ

## ทดสอบ Logic

มีชุดกรณีตรวจ logic ที่ `tests/test_logic.py` ครอบคลุมข้อมูลผิด, เมนูหมด, สั่งเกินสต็อก, ไม่มีสิทธิ์, ข้อมูลซ้ำ, server-side string validation, นามสกุลไฟล์ผิด และคำนวณบิล:

```bash
python -m unittest discover -s tests
```

โค้ดกฎธุรกิจอยู่ใน `restaurant/logic.py` (ฟังก์ชันมีพารามิเตอร์และคืนค่า), persistence อยู่ใน `restaurant/storage.py`, และ Flask routes อยู่ใน `app.py` แยก Python modules อย่างน้อย 2 ไฟล์ ใช้ list/dict/tuple/set, for/while, int/float/str/bool, if/elif/else และ try/except โดยโมดูลกฎธุรกิจไม่พึ่ง third-party library

## Deploy บน Vercel

มี `vercel.json` และ entrypoint `api/index.py` ให้ deploy โปรเจกต์นี้ได้โดยใช้ Python runtime:

1. นำโฟลเดอร์นี้เข้า Git repository และเชื่อม repository ใน Vercel
2. ตั้ง Environment Variable `SECRET_KEY` เป็นค่าสุ่มที่ยาวและไม่ซ้ำ
3. Deploy โดยใช้ค่า build/output เริ่มต้นของ `vercel.json`

**การเก็บข้อมูล:** SQLite ถูกออกแบบเป็นฐานข้อมูล local สำหรับรันและสาธิต โปรเซส Vercel ใช้ filesystem ชั่วคราว จึงไม่เหมาะเก็บข้อมูลจริงข้ามการ deploy/instance; ก่อนใช้งานจริงให้เปลี่ยน `restaurant/storage.py` ไปใช้ฐานข้อมูล managed ที่ persistent และย้ายไฟล์ภาพไป object storage. การ deploy สำหรับสาธิตจะแสดงโครงงานและ UI แต่ไม่รับประกันการคงข้อมูลหลัง cold start.

## ขอบเขตและต่อยอด

QR สั่งอาหารสาธารณะ, split bill, stock deduction ตามสูตรวัตถุดิบ, แต้มสมาชิก และ WebSocket real-time ถูกเก็บไว้เป็นแนวทางต่อยอด; โครงสร้างฐานข้อมูลเริ่มต้นมี reservations, ingredients/recipes และ members ให้รองรับการพัฒนาต่อ ส่วน Kitchen Display ปัจจุบันอัปเดตเมื่อเปิด/รีเฟรชหน้า

## โครงสร้าง

```text
app.py                    Flask routes / server-side validation
restaurant/logic.py       กฎธุรกิจ Python standard library
restaurant/storage.py     schema, SQLite, seed และ audit log
api/index.py              Vercel Python entrypoint
templates/                หน้าจอเว็บภาษาไทย
static/style.css          รูปแบบ responsive และใบเสร็จพิมพ์ได้
samples/                  ตัวอย่าง TXT, CSV, JSON
tests/test_logic.py       Logic tests ตามกรณี rubric
```
